# UI精査の記録（2026年10月1日・版 2026.10.01-r5）

対象：20〜30代の女性とその子ども。チラシ（水色の枠と白い波、パステルの貝の線画、濃紺の文字）の世界観を守りつつ、先進性も出す。
確認環境：Claude Code デスクトップアプリ内のブラウザ（Chromium 系）で、画面幅 320・375・414・768px をエミュレーション。**実機（iPhone・Android）では未確認**。

## 1. 見た目と操作の目線ごとの確認

| 目線 | 見たところ | 直したこと |
| --- | --- | --- |
| 世界観（チラシとのつながり） | 表紙の外が単色で平板。チラシの「貝の線画」「水色と白い波」が表紙の中にしかない | 背景に、チラシの線画に合わせた淡い貝の模様（このサイト用に作成）を敷いた。表紙の下にチラシの波の帯。ヘッダーのロゴを文字が切れない形に作り直し、表紙はロゴ全体が入るよう切り出し直した |
| 先進性 | 画面の切り替えや操作に動きがなく、静的 | 画面がふわっと現れる動き、押したときの縮み、記録の進み具合のリング、AI判定中の光が流れる演出と結果の棒が伸びる動き。日本語を文節で折り返す新しいCSS（`word-break: auto-phrase`）。端末の「動きを減らす」設定では動きを止める |
| 初めて使う人 | 「貝を探す」の絵が何を表すか分かりにくい | 3種類の貝と虫眼鏡の絵に描き直した。入口の順は「貝を探す」を先頭に |
| 子ども連れ・片手 | 修正のボタンが小さい／状態が分かりにくい | 状態ボタンは高さ52px以上、選んでいるものは濃紺で塗りつぶし。前後の貝のボタンは2段にして押しやすく |
| 何度も来る人 | ホームの記録欄で「要確認1」が「要確／認1」と途中で折り返す | 記録欄は「箱の記録 8/36」と「要確認 1」の札に分け、リングで進み具合を表示 |
| 屋外の強い日差し | いちばん小さい文字（12.5px）が読みにくい | 最小を13pxに。文字のコントラストは4.5:1以上（本文14.6:1、補助8.2:1） |
| 箱の画面 | 未記録のマスに「－」が並び、ごちゃついて見える。「8/36」がリングと文字で二重 | 未記録は番号だけにした。凡例も同じ見た目に。数字の重複をなくした |
| 見比べチェック | 幅320pxで「わからない」が「わからな／い」と折り返す。写真の列の説明文が不自然に折り返す | ボタンの文字を1行に収めた。重複する説明文を削除し、観点の説明は項目の下に1行で |
| 狭い画面（320px） | 画面の題名が「…」で省略される（3画面）。小さいボタンの文字が折り返す | 題名は省略せず折り返す。ロゴを少し小さく。2つ並ぶ小さいボタンは絵記号を省いて1行に |
| 一覧 | 絞り込みボタンが3段に広がる | ボタンを詰め、「すべての形」→「すべて」、「空いているマスの貝」→「空きマスの貝」 |
| 貝の写真 | 一覧表からの切り出しで、18枚ほど貝の下側が欠け、文字の切れ端が残る | 写真の中の貝の形を画像から検出して切り出す方式に変え、36枚すべてで欠けと文字の残りをなくした（一覧表で番号バッジが重なっていた角だけは元画像に情報がない） |

## 2. 自動チェック（`tools/ui-audit.js`）

全14画面＋AI判定の結果・見比べチェック・読み取りの範囲あわせと結果確認・カメラ画面を、幅 320・375・414・768px で確認。

- 画面の横幅からのはみ出し
- 文字が枠で切れていないか
- 「…」で省略されていないか
- 画像が枠で切り取られていないか
- ボタン・ラベルの文字が言葉の途中で折り返していないか（実際の文字の行を数える）

最終結果：**すべての幅で指摘なし**。

使い方（開発用サーバーで開いたサイトのコンソール）：

```js
const { runAll } = await import('/tools/ui-audit.js'); await runAll();
```

## 3. まだ確かめられていないこと

- iPhone（Safari）・Android（Chrome）の実機での見た目・操作。特に `word-break: auto-phrase`（文節での折り返し）は Safari では効かないため、iPhone では一部の文が言葉の途中で折り返す可能性がある（主な箇所は区切りを個別に入れて対策済み）
- 文字を大きくする設定（200%）での表示
- 読み上げ（VoiceOver・TalkBack）での操作
- 屋外の日差しの下での見え方
- 対象の年代の方に実際に使ってもらう試験
