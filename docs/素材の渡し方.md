# 素材（写真）の撮り方と渡し方

用途ごとに、必要な写真が違います。どれも、スマホのカメラ（iPhone の HEIC のままでも可）で撮れます。
撮影する人と、写真に写る物の権利は、`ASSETS.md` の素材台帳に記録してください。人の顔や個人情報が写らないようにしてください。

| 用途 | 置く場所 | 1種類あたりの枚数 | 反映のしかた |
| --- | --- | --- | --- |
| ① 図鑑の写真（サイトに表示） | `materials/photos/` | 表・裏（できれば横）の3枚 | `python3 tools/import_photos.py` |
| ② AI判定の学習・評価 | `training/photos/01/`〜`36/`、`other/` | 30枚以上（別の個体を3つ以上） | `python3 tools/make_training_manifest.py` → `tools/train.html` |
| ③ 3Dモデル（**見送り**） | ― | ― | 2026年10月5日に見送り。下の③は記録として残す |

## ① 図鑑の写真

**名前の付いた写真のフォルダをそのまま取り込む**（2026年10月〜）：「1.すずめ貝.jpg」「1.すずめ貝2.jpg」のように、ファイル名に貝の名前が入っていれば、名前でサイトの番号に対応させ、貝のまわりを自動で切り出して、図鑑の写真とAIの学習用の両方に取り込みます。

```bash
python3 tools/import_reference_photos.py "/Volumes/写真保存用HD/Backup　別ハードディスク/貝写真/編集後/" --source "2026年10月 撮影" --max-per-species 9
python3 tools/make_training_manifest.py
```

続けて http://localhost:8736/tools/train.html で学習し直します（「図鑑の写真」のチェックは外す。同じ写真が学習用にも入っているため）。名前の書き方が違うときは `tools/photo_names.json` に足します。

以下は、表・裏・横の名前で取り込む方法です。

- 背景は白か淡い無地（紙・布）。影が強く出ない明るい日陰や窓際で
- 貝が画面の7〜8割の大きさになるように。ピントは貝に
- ファイル名：`01-front.jpg`（表）、`01-back.jpg`（裏）、`01-side.jpg`（横）。番号は2桁
  - 「01_表.jpg」「01-裏.HEIC」の書き方でも読めます
- 取り込み：

```bash
python3 tools/import_photos.py materials/photos --source "2026年10月 志賀町商工観光課 撮影"
```

利用許諾と番号の対応を確認済みにするときは、`--rights-confirmed --rights-holder "志賀町" --mapping-confirmed --by "確認した人"` を付けます（付けないと、一般公開の画面には出ません）。

## ② AI判定の学習・評価用の写真

### スマホで集める（いちばん簡単。2026年10月〜）

1. スマホで **https://sakura-shell.github.io/#/collect?staff=1** を開く（スタッフ向けの説明書 `docs/staff/` のQRコードから。合言葉のあと「学習用の写真を集める」画面が出る。一度開いたスマホは、次から「写真で調べる」画面にスタッフ用のボタンが出る。`?staff=0` で解除）
2. 「どの貝か」を選び、「カメラで撮る」か「写真を選ぶ」（何枚でもまとめて選べる）
3. 同じ種類の**別の貝**を撮るときは「別の貝（次の個体）に切り替える」を押す
4. 写真で調べて記録したときも、スタッフ用モードなら「撮った写真を学習用に保存」で貯められる
5. **その日のうちに**「ZIP で書き出す」→ ZIP をパソコンへ送る（AirDrop・メールなど）。送ったら「書き出し済みの写真を消す」。iPhone などでは、数日サイトを開かないと保存した写真が消えることがある
6. パソコンで取り込んで学習し直す：

```bash
python3 tools/import_collected.py ~/Downloads/shell-photos-20261005.zip
```

続けて http://localhost:8736/tools/train.html で学習し直す（「図鑑の写真」のチェックは外す）。写真はスマホの中だけに保存され、ZIP で書き出すまで外部には送られない。

**目安：1種類 30枚以上・別の貝 3個以上**（画面に進み具合が出る）。36種類以外の貝・石・ガラスも「36種類以外」で100枚ほど集めると、「36種類以外かも」の判定を使えるようになる。

### パソコンでフォルダに置く場合

AIの成績は、この写真の量と多様さで決まります。**海岸で利用者が撮るのと同じ撮り方**で集めるのが大事です。

- 1種類につき、**別の個体（別の貝）を3つ以上**、それぞれ10枚前後（合計30枚以上）
- 置き方を変える：手のひらの上、砂の上、白い紙の上、濡れた状態・乾いた状態
- 向きを変える：表・裏・斜め。明るさも変える（晴れ・曇り・日陰）
- 同じ個体の写真はフォルダにまとめる：`training/photos/12/kai-a/…`、`training/photos/12/kai-b/…`
  （評価のときに「学習に使っていない貝」で正解率を測るため）
- 36種類以外の貝・石・ガラス片の写真も `training/photos/other/` に集めると、「36種類以外かも」を出せるようになる（目安100枚以上）
- 手順：

```bash
python3 tools/make_training_manifest.py
python3 tools/serve.py
```

ブラウザで http://localhost:8736/tools/train.html を開き、「学習して評価する」→ 結果を確かめて「サイトに保存する」。
成績（評価用の写真での正解率）は `docs/ai-evaluation.json` に残ります。一般の利用者に出すかは、成績を見て `site/data/config.json` の `features.identify` を `"public"` にして決めます。

## ③ 3Dモデル用の写真（Mac の Object Capture で作成）

- 貝を回転台（なければ紙の上で少しずつ回す）に置き、**高さを変えて2〜3周**、1周24〜40枚。隣の写真と7割ほど重なるように
- 裏側も必要なら、貝を裏返して同じように撮り、同じフォルダに入れる
- 背景は無地。光は均一に（強い影・テカリを避ける）。ピントは貝全体に
- 小さな貝（2cm以下）や、白くツルツルした貝・半透明の貝は、作るのが難しいことがあります
- 標本の長さ（いちばん長いところ）を定規で測っておく（ARの実物大表示に使う）
- 作成：

```bash
python3 tools/make_model.py 12 materials/3d/12 --length-mm 38
```

できた3Dモデルは、確認用プレビューの詳細画面の「3Dで見る」で確かめられます（「照合待ち」の印が付く）。
実物と見比べて問題なければ、`--confirmed --by "確認した人"`（長さも実測済みなら `--size-confirmed`）を付けて登録し直します。

### ③-2 Scaniverse などのアプリで作った3Dモデルを使う場合

書き出しは **GLB** を選びます（OBJ の ZIP でも可。STL・PLY・LAS は色がない／点の集まりなので使えません。USDZ は iPhone 専用なので使いません）。

```bash
python3 tools/import_model.py 12 materials/3d/12_scaniverse.glb --length-mm 38
```

大きさを実測の長さに合わせ、中心をそろえ、色の画像を縮めて（長辺2048px）、`site/models/12.glb` に登録します。Draco 圧縮はオフにして書き出してください。

### ③-3 小さい貝（1〜3cm）を撮るとき

Scaniverse の LiDAR（距離センサー）での読み取りは、数cmの物には向きません。小さい貝は、**写真から作る方法（③の Object Capture）**のほうが向いています。

- スマホのマクロ撮影（iPhone Pro の自動マクロ、またはクリップ式のマクロレンズ）で、貝が画面の6〜8割になるまで近づく
- 貝を小さな台（コルク・練り消しで立てたつまようじなど）にのせ、少し浮かせると裏側の縁まで写る
- 下に新聞や模様のある紙を敷くと、写真どうしの位置合わせがしやすくなる
- 明るさは均一に（曇りの日の窓際、白い紙で光を和らげる）。テカリと強い影を避ける
- ピントと明るさを固定（画面を長押しで AE/AF ロック）
- 高さを変えて3周、1周20〜30枚、合計60〜100枚。裏返して同じように撮り、同じフォルダに入れる
- 白くツルツルした貝・半透明の貝・濡れた貝は、作れないことがあります（乾いた状態で撮る）

### ③-4 動画から作る場合

写真の代わりに動画でも作れます。動画から静止画を切り出して、③と同じ方法で作ります。

- 撮っている間、**貝は動かさない**（手で持つ・置き直すと使えない）。動くのはスマホだけ
- 貝のまわりを**ゆっくり**（1周20〜30秒）、高さを変えて2〜3周。貝が画面の5割以上の大きさになるまで近づく
- 下に模様のある紙（新聞など）を敷く。白くツルツルした机は、位置合わせの手がかりがなく、テカリも出るので向かない
- ピントと明るさを固定（AE/AF ロック）。4K・30コマで撮る
- 裏側も作るときは、裏返して**別の動画**にする

表と裏を1本ずつ撮った動画から、まとめて作れます（動画の切り出し・背景の紙の除去・表裏の登録まで自動）。

```bash
python3 tools/make_model.py 5 materials/3d/05/表.MOV --back materials/3d/05/裏.MOV --crop --length-mm 21 --style sakura
```

- `--crop`：下に敷いた紙を色で見分けて取り除き、輪郭のギザギザと面の凸凹をならす。**緑・青など、貝と違う色の無地の紙**の上で撮る（このときは高精細 `full` で作る。1本あたり1〜3分）
- `--length-mm`：`--crop` のときは**殻の片方の長さ**（二枚貝が開いた形でも、片方で測る。巻貝など1個の貝は `--parts 1` も付ける）
- `--style sakura`：色・質感を、さくら貝らしい桜色とつやに加工する（イラスト寄り。画面に「加工しています」と出る）
- 置いたまま撮ると、下の面は写らない。表と裏は別のモデルになり、画面の「表／裏」で切り替える

動画の一部だけを使うときは、先に静止画を切り出してフォルダを渡します。

```bash
tools/bin/videoframes materials/IMG_0000.MOV materials/3d/05 4 0 40   # 1秒4枚、0〜40秒を切り出す
python3 tools/make_model.py 5 materials/3d/05 --crop --length-mm 21
```

できたモデルは、次のコマンドで10方向から見た画像にして確かめられます。

```bash
swiftc -O -parse-as-library tools/photogrammetry/RenderViews.swift -o tools/bin/renderviews
tools/bin/renderviews materials/3d-work/05/obj/baked_mesh.obj 確認.png
```
