## 改善方針

### 1. 色（ご指定のパレットを、読みやすさを確かめて役割分担）

白い文字をサクラピンク（#EFA9B8）にのせると明るさの差が 1.9 しかなく読めないため（目安は4.5以上）、ピンクは「面」に使い、文字をのせるボタンは同じ系統の濃い色にする。

| 役割 | 色 | 使う場所 |
| --- | --- | --- |
| サクラピンク（メイン） | #EFA9B8 | 選んでいる状態の面、進み具合のリング、見出しの印、アクセント |
| さくら色（濃い） | #A84762 | 主なボタン（白文字との差 5.6）、選んでいる絞り込み |
| ペールピンク（補助背景） | #FFF1F4 | 「写真で調べる」の入口、お知らせ、選択中のタブ |
| シーグラスブルー（サブ） | #A9DCE3 | 海の要素（波の帯・区切り）、補助の入口 |
| 海の色（濃い） | #2C6F79 | 水色の面にのせる文字 |
| シェルゴールド（アクセント） | #D5B77A | レア度の星、特別な枠、図鑑の入口 |
| ウォームホワイト（背景） | #FFFDFB | ページの背景 |
| ダークグレー（本文） | #39434A | 本文（背景との差 10.0） |
| 濃紺（見出し） | #2E3A6E | 見出し・番号の印。チラシのロゴの線の色（差 10.6） |
| 収集箱の水色 | #45BFE3 系 | 収集箱の絵（実物の箱の色なので残す） |

### 2. デザインの部品をそろえる（CSS 変数＝デザイントークン）

- 文字：12・14・16・18・20・22・26・30px の8段（`--fs-*`）
- 角の丸み：6・12・16・20・24px と半円（`--r-*`）。カード20、ボタンは半円、小さい部品12
- 影：小・中・大・押したときの4種類（`--shadow-*`）。色味は濃紺から、ほんのりピンクのグレーに
- 余白：4・8・12・16・24・32px（`--sp-*`）
- 動き：短い（0.12秒）・ふつう（0.24秒）と、同じ動き方（`--ease`）
- 以前の色の名前（--navy など）は、新しい色の別名として残す（書き換えもれがあっても色がそろう）

### 3. 共通の部品から直す

ボタン（主・白・淡い・文字だけ・小）、カード、お知らせ、絞り込み、切り替え、タグ・状態の札、番号の印、検索欄、上の帯、下のタブ、下から出る画面・導入・知らせを、1か所の指定にまとめ、すべての画面で同じ見た目にする。

### 4. 画面ごとの調整

- ホーム：入口の3枚を同じ形・同じ影にし、色は「写真で調べる＝ペールピンク／図鑑＝ゴールド／収集箱＝海の色」で役割を分ける
- 背景：ウォームホワイトに、チラシの貝の模様を薄く
- 下のタブ：選んでいる画面をペールピンクの丸い面と濃い文字で
- 「このサイトについて」の表の崩れを直す

### 5. 守ること

収集の機能・保存データ・アドレス・画像・データは変えない。変えるのは見た目（CSS と、色を直接書いていた一部の部品）だけ。
変更後に、スマホ2サイズとパソコンで全画面を撮って比べ、表示崩れの自動チェックと、記録・取り消し・読み取りの動作を確かめる。

## 実装と確認（r21）

- `site/assets/css/style.css`：先頭にデザイントークン（色・文字・角の丸み・影・余白・動き）。以前の色の名前は新しい色の別名。文字の大きさ・角の丸み・色の直接指定を変数に置き換え（直接の色はカメラ画面の黒だけ、文字は8段＋小さな札用）。末尾に「共通の部品」をまとめ、全画面の見た目をここでそろえる
- アイコン・背景の模様の線の色を新しい濃紺に。ホームの画面の色（theme-color）をウォームホワイトに。背景の模様は少し薄く
- 作業後の画面：`docs/screens/design-after.jpg`
- 確認：表示崩れの自動チェック（幅320・375・390、文字130%、横向き）指摘なし／10画面の文字と背景の明るさの差はすべて基準以上（ふつうの文字4.5、大きな文字3）／記録・取り消し・絞り込み・エラーなし
